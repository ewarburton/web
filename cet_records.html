One machine per distinct (R, L2), best first. Click any row to show it above. Unnamed rows carry a derived alias: the rank offset from the nearest named machine, so Undecomet is one below Comet, Duovixen is two above Vixen and Univixen one above it. These are generated by formula and frozen by machine string; only the named machines keep chosen names.
None of these values can be tested by running the machine. On every one of them a single agent stays inside a band that grows in slow stages: it settles at about L2, and the next stage is roughly 10L2 steps away. So each of them shows no collision for any horizon anyone can run — which the model predicts, so that is evidence neither way. A search for an exact repeat inside the band (Brent's algorithm over the tape window, 5×1010 steps) finds none either, so non-halting is not proved here. Rudolph and Firstal are the one place a stage change is visible: their counter steps up to about their own L2 at roughly 548,500 steps.
