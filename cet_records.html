One machine per distinct (R, L2), best first by the claimed value. Boot order is diagnostic only. Click any row to show it above. Unnamed rows carry an E/G structure coordinate; a manual name is shown with its coordinate. In family views, every family gets a header (singletons included), and headers list manual members but never promote them above a better-valued row.
None of these values can be tested by running the machine. On every one of them a single agent stays inside a band that grows in slow stages: it settles at about L2, and the next stage is roughly 10L2 steps away. So each of them shows no collision for any horizon anyone can run — which the model predicts, so that is evidence neither way. A search for an exact repeat inside the band (Brent's algorithm over the tape window, 5×1010 steps) finds none either, so non-halting is not proved here. Rudolph and Firstal are the one place a stage change is visible: their counter steps up to about their own L2 at roughly 548,500 steps.
E-G ladder (0 round certificates) order
The engine-glider pairs from the first 16,000 that produced a round certificate, best first: more rounds R, then depth L2. Only 613 of those 16,000 did; the rest returned weak, no-glider or no-gate-valid-bounce, which says nothing about whether they halt. Same model claim as the table above, not a proof. The engine-family view collapses this list to 13 groups; rank is the default.
R-boot / L2-boot / L0-boot are the same pipeline re-run at boot 5,000, split into three columns so the numbers can be read separately. Where it still yields a value the cells are R / L2 / L0; otherwise the three columns carry the reason it doesn't (no gate, alive, drift). The certificates themselves are a boot-4,000 convention. L0 is unchanged by the boot in every machine that still produces a value; R and L2 are not. The sweep already includes 20,000; the visible boot columns stay at 5,000 because that is a small fixed perturbation, not because 20,000 is unavailable.
variance shows summarises a seven-boot sweep (3,999 / 4,000 / 4,001 / 4,010 / 5,000 / 10,000 / 20,000): Stable — same R, L2 within 2%; Drifting — same R, L2 wanders further; Halts Differently — R moves, so the tower height changes; Alive / No Gate — no certificate at any boot; Mixed — some boots halt, some do not. R is the soft number here: Comet is R=7 at boot 3,999, R=25 at 4,000, R=10 at 5,000, and R=15 at 20,000, while L2 stays in 1,012–1,030. The R change is the model's round count moving, not an observed halt. Tritrimestrius shows the same at a different scale: 22/50,970/11 at 4,000 and 5/50,982/11 at 5,000 (L2 +0.02%, R 22 → 5), which is why it is Halts Differently, not Stable.
R and L2 are round-pass claims, not proofs. Deever's 10↑↑140 is a community claim this pipeline has not reproduced — it lies outside the sweep, which is why it has no L2. Open a machine in the viewer to simulate it.
